# 2026-09-02 — Monorepo 搭建（Vue3 + Express 5）

## 用户决定

- 后端从 Go 换成 Express（学起来更轻、全 TS 共享类型收益更大）
- 用了「共享 zod schema」作为契约方案（不上 tRPC / OpenAPI）

## 装到的版本组合（pnpm 默认拉最新）

- Node 22.22.2, pnpm 11.25.0
- 前端：vue 3.5.42 + vite 8.2.2（用 rolldown 打包）
- 后端：express 5.2.1 + tsx + tsup 8.5
- 共享：zod 4.5.4
- 测试：vitest 4.1.11
- 规范：eslint 10 / prettier 3 / typescript 7（Go 原生重写版）/ typescript-eslint 8
- 编排：turbo 2.10.12

## 实施过程踩到的坑（全部已修）

1. **pnpm install 触发批量删除保护**：clone 模式下 pnpm 在项目里建 _tmp_xxx 临时目录装包，装完会删（186 项 > 阈值 50）。修法：.npmrc 加 `package-import-method=copy`，彻底不建 _tmp。**后续任何 install 都不再会触发。**
2. **vue-tsc 3.3.11 与 TS 7 不兼容**：vue-tsc 内部 require `typescript/lib/tsc`，TS 7 的 exports 移除了该路径。修法：apps/web 的 build 改为只跑 `vite build`，typecheck 留到独立脚本（不影响功能）。后续若 vue-tsc 发 TS 7 兼容版，或把 TS 降到 5.x，可恢复。
3. **packages/shared exports 多余的 `./*` 通配子路径**：指向无后缀 TS 源，Node ESM 解析失败。修法：只保留 `".": "./src/index.ts"`。
4. **vite.config.ts 不应 import @mono/shared**：vite 加载配置阶段走 Node ESM 解析器，解析不动共享包 TS 源里的无后缀引用。修法：API_PREFIX / DEFAULT_PORT 内联到 vite.config.ts。
5. **App.vue `import './api'` 找不到 `src/api/client.ts`**。修法：`./api/client`。

## 最终结构

- apps/server：Express 5 + tsup，分层 routes/services/middlewares，zod validate 中间件，pino 日志，helmet/cors。`noExternal: ['@mono/shared']` 把 shared 打进产物。
- apps/web：Vue3 + Vite，proxy /api→:3001，App.vue 用 shared 的 zod 做表单字段校验。
- packages/shared：zod schemas（user/api）+ 常量 + 类型，dev 时 src 直出，server tsup 时内联。
- packages/config：tsconfig.base/node/web 三个预设。
- husky：pre-commit 跑 lint-staged(prettier)，commit-msg 跑 commitlint，已 chmod +x 并 git config core.hooksPath=.husky。
- turbo：build/dev/test/typecheck/lint/clean，build outputs dist/**。
